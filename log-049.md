# Log 049 --- Book I as a Test of the Book Zero Layer

## From a planned experiment to an actual proof corpus

Log 045 began the reconstruction of Book I with a specific question:

> How much of a classical synthetic proof becomes routine once Book Zero
> is available?

The first part of Book I now provides enough evidence to begin answering
that question.

The reconstruction has progressed proposition by proposition beyond the
initial constructions and congruence results. In doing so, Book Zero has
ceased to be merely a reconstructed corpus of elementary theorems. It is
now being used as working infrastructure inside larger proofs.

The result is not uniform. Some Euclidean propositions collapse almost
completely into previously established interface results. Others expose
a real difference between Euclid's proof and the proof naturally
available over the Hilbert development. Still others reveal that a
definition chosen in Book Zero already contains most of the existential
content of the corresponding Euclidean proposition.

This is the first substantial test of the working-layer hypothesis
introduced in Logs 042--045.

## 1. Three levels are now visible

The reconstruction increasingly separates into three mathematical
levels:

``` text
Hilbert foundation
       |
       v
Hilbert interface + Book Zero
       |
       v
Euclid Book I propositions
```

The important observation is that the middle level is doing real work.

Book I propositions frequently do not need to descend to primitive
incidence, order, and congruence axioms. Instead they can be expressed
using operations and theorems already available at the Hilbert-interface
or Book-Zero level.

This is exactly the behavior expected from a useful working language of
synthetic geometry.

## 2. Some propositions become thin wrappers

Several early propositions illustrate the strongest possible form of
reuse.

### Proposition I.2

Euclid's construction transports a given segment to a prescribed
endpoint using an equilateral triangle, two circles, produced lines, and
subtraction of equal segments.

In the reconstruction, the corresponding operation is already available
as

``` text
bookZero_49_layoff
```

Once a ray and a nondegenerate segment are supplied, the theorem
produces the required point on that ray with the required segment
congruence.

At the Book I level, Proposition I.2 is therefore essentially an
interface call.

### Proposition I.3

The compression is even more striking for Proposition I.3.

The formal hypothesis

``` text
HilbertSegmentLess Geo C D A B
```

already contains a witness point on the greater segment together with
the relevant congruence. The Book I theorem extracts this witness and
reverses the orientation of the congruence.

Thus a proposition that is classically a construction can become almost
definitional once strict segment comparison has been represented in a
sufficiently useful form.

### Proposition I.4

The formal Proposition I.4 is a thin wrapper around the established SAS
interface:

``` text
TriangleCongruentFromSAS
```

The Book I theorem does not reconstruct Euclid's superposition argument.
The foundational work required to justify SAS has already been performed
below the Book I layer.

These examples show one role of Book Zero and the Hilbert interface very
clearly: they allow later proofs to be written at the level of the
geometric operation actually being used rather than at the level of its
original construction.

## 3. Reuse does not imply translation

The first propositions also show that reconstruction should not be
confused with line-by-line translation of Euclid.

For Proposition I.1, Euclid constructs the third vertex of an
equilateral triangle as the intersection of two circles. The Lean proof
instead obtains an equidistant point from the Hilbert interface and then
proves that it cannot be collinear with the base points. Betweenness
trichotomy and

``` text
bookZero_45_partNotEqualWhole
```

exclude the three possible collinear orders.

The result is the same proposition, but the proof architecture is
different.

Proposition I.6 provides another example. Euclid argues by
contradiction: assuming unequal sides, he cuts off an equal segment and
applies SAS. The formal proof uses an already established ASA result
directly.

Propositions I.7 and I.8 make the contrast still sharper. Euclid's
arguments are closely tied to positional configurations and
superposition. The Hilbert reconstruction can instead use congruence and
uniqueness results that eliminate much of this case-sensitive reasoning.

The emerging pattern is therefore:

``` text
same mathematical proposition
          |
          +-- classical Euclidean proof architecture
          |
          +-- Hilbert / Book Zero proof architecture
```

The reconstruction preserves the theorem, but not necessarily the
historical proof route.

## 4. Book Zero is useful precisely when it changes the scale of the proof

The most useful Book Zero results are not merely frequently cited
lemmas. They change the scale at which a later proof can be expressed.

A layoff theorem replaces a multi-stage construction.

A segment-order relation can package an existential witness.

A part-not-equal-whole theorem can replace repeated low-level
betweenness arguments.

Ray and angle uniqueness results can replace positional case analysis.

This suggests a more precise interpretation of the working-layer idea.

Book Zero is useful when it permits a proof to move from statements
about primitive relations to statements about recognizable synthetic
operations.

In schematic form:

``` text
primitive relations
        |
        v
reusable synthetic operation
        |
        v
classical proof step
```

The middle node is not merely an organizational convenience. It changes
the granularity of formal reasoning.

## 5. The documentation changed the experiment

During the Book I reconstruction, the proposition documentation became
more detailed. Each proposition is now examined not only as Lean code
but through several parallel views:

-   the classical Euclidean statement and proof;
-   the geometric diagram;
-   the Hilbert reconstruction;
-   the actual Lean dependency structure;
-   the relationship with earlier propositions and Book Zero results.

This comparison has proved mathematically useful.

It exposed cases where an earlier description incorrectly suggested that
the Lean proof reproduced Euclid's construction. Inspection of the
actual source showed instead that the formal theorem used a stronger
existing result.

It also made visible a distinction that was easy to miss while
concentrating only on compilation:

> a formal reconstruction of a proposition is not automatically a formal
> reconstruction of Euclid's proof of that proposition.

That distinction will be treated separately in the next stage of the
analysis.

## 6. The role of diagrams also changed

The documentation review initially appeared to be a presentation
problem: some propositions contained too many diagrams, repeated
snapshots of the same construction, or figures that were difficult to
read.

The review showed that diagrams can serve a more serious purpose.

Comparing the formal reconstruction with classical diagrams makes hidden
assumptions and positional cases visible. In the first propositions this
includes circle intersection, line extension, the side chosen in a
superposition argument, and the multiple configurations underlying
Proposition I.7.

For that reason the current documentation no longer attempts to
illustrate every construction instruction.

The working rule is now:

> A diagram should represent a geometrically distinct configuration or
> clarify a logically significant step.

Repeated snapshots that merely add one point or one segment are normally
removed.

## 7. Code presentation follows the same principle

A similar change has been made in the presentation of Lean code.

Since the complete source is available in the repository, reproducing
long theorem bodies in the documentation adds little value. Code
excerpts are now retained only when they expose a mathematical feature
of the reconstruction.

Typical examples are:

``` text
bookZero_49_layoff
HilbertSSS
hilbert_asa_sides
hilbert_angle_unique_common_ray
```

The documentation explains why such a call matters and what classical
work it replaces.

The full implementation remains in the source repository.

This makes the proposition documents analytical rather than archival.

## 8. What the first part of Book I has established

The experiment begun in Log 045 can now be stated more sharply.

Book Zero does function as a practical working layer for Book I, but its
value is not measured simply by the number of direct theorem calls.

The important evidence is structural:

1.  substantial classical constructions can become named reusable
    operations;
2.  elementary order arguments can be hidden behind stable theorem-level
    interfaces;
3.  Book I proofs can often remain above the foundational Hilbert
    axioms;
4.  the same Euclidean proposition can admit a substantially different
    formal proof architecture;
5.  examining those differences reveals which pieces of synthetic
    reasoning deserve to be reusable infrastructure.

This is stronger evidence for the working-layer hypothesis than merely
completing another sequence of propositions.

## 9. Next question

The reconstruction now raises a question that was only implicit when
Book I began:

> What exactly is being preserved when a classical proposition is
> reconstructed over a modern axiomatic interface?

The theorem statement may be preserved while the proof architecture
changes radically.

Sometimes a Euclidean construction becomes a Book Zero operation.

Sometimes a superposition argument becomes a congruence theorem.

Sometimes a positional proof becomes a uniqueness argument.

These are not implementation accidents. They reveal the relation between
two organizations of synthetic geometry.

Logs 047 and 048 examined two consequences of this stage in detail: the
distinction between classical proofs and formal reconstructions, and the use
of diagrams as instruments of proof analysis.

## Current status

The first part of Book I has been reconstructed and its documentation
has undergone a systematic proof-and-diagram audit.

The principal result of this stage is methodological:

> Book Zero is no longer only a reconstructed preliminary corpus. It has
> begun to operate as the intermediate language in which Book I proofs
> can be expressed.

At the same time, Book I has shown that successful reuse of this
language often changes the architecture of the proof itself.
