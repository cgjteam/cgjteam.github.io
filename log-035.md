# Log 035 — Common Infrastructure Audit

## Objective

This session continued the architectural audit of the geometry library with the goal of identifying theory-independent components that could be extracted into a shared `Common` layer.

Unlike previous refactorings, the purpose was not to introduce new mathematical abstractions, but to verify whether existing code represented common infrastructure or genuine geometry.

## Completed refactoring

The following representation-independent infrastructure is now provided by `Common`:

- `UnorderedPair`

- `Segment`

- `PairRelation`

- endpoint reversal for relations on unordered pairs

The endpoint reversal lemmas are now implemented once and reused by the geometry foundations.

## Interface audit

The three interface layers (`HilbertInterface`, `TarskiInterface`, `SuppesInterface`) were compared declaration by declaration.

### Collinearity

The first audit examined the family of collinearity permutation lemmas.

Although the mathematical statements are analogous, their logical origins differ.

- Hilbert: wrapper around the Hilbert primitive collinearity theory.

- Tarski: consequence of the definition of collinearity as a disjunction of betweenness relations.

- Suppes: theorem derived from axioms L2 and L3.

Therefore these lemmas remain local to their respective theories.

### Congruence

The second audit examined congruence permutation lemmas.

A distinction emerged between two different kinds of properties.

Properties such as congruence symmetry remain geometric and therefore belong to individual theories.

In contrast, reversing endpoints of a segment is now purely a consequence of the representation by unordered pairs.

Consequently:

- `CongruentSwapSecond` in the Hilbert interface was reduced to a direct wrapper over the common representation lemma.

- `tarski_congruent_reverse_both` was rewritten to use the common endpoint-reversal mechanism instead of a geometric proof based on Tarski axioms.

Both changes compiled successfully without affecting the public API.

## Conclusions

The audit confirms that the current architecture naturally separates into:

```

Common

    ↓

Core

    ↓

Axioms

    ↓

Interface

    ↓

Proofs

```

No additional theory-independent components were identified in the axiom layers.

The interface audit remains open for further families of lemmas, but the congruence endpoint-reversal refactoring demonstrates that representation-level properties can now be shared across multiple geometry foundations.

## Result

The Common layer is no longer limited to shared data structures.

It also provides shared representation properties that can be reused uniformly by Hilbert, Tarski and future geometry foundations.
